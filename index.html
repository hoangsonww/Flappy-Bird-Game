What is in it

A small game, taken seriously

Everything below runs on the device with no account, no network and no setup. The backend adds a social layer on top — it never gates the game.

🎮

Six modes

Classic, Endless, Time Attack, Hardcore, Zen for practice, and a daily challenge everyone plays identically.

⚡

Five power-ups

Shield, slow-motion, coin magnet, double points and shrink. Re-collecting one extends it rather than replacing it.

🪙

Coins and combos

A coin streak multiplies rewards up to ×8 — so the safest line through a gap is rarely the most interesting one.

🌪️

Weather and time of day

Wind, rain and fog rolled from the run seed, and a world that cycles through sunset, night and dawn every 20 pipes.

👻

Ghost replays

Your best run is recorded at 20 Hz and replays beside you. Outfly it to unlock the one secret achievement.

🏆

18 achievements

955 points, unlocked offline and reconciled with the server later. The merge only ever moves progress forward.

🐦

Eight bird skins

Bought with coins you actually earned. Cosmetic only — there is nothing to buy with real money.

♿

Accessibility

Reduce flashing, high contrast, VoiceOver labels, and full support for the system Reduce Motion setting.

Screens

Every screen, captured by a script

The app takes launch arguments to open any screen directly and to fly itself, so make media regenerates all of this without anyone tapping a simulator.

Optional backend

Leaderboards, if you want them

A complete Node.js + TypeScript API with accounts, ranked boards, achievement sync and a daily challenge. Start it with one command — the game finds it on its own.

📱 The game

  • Swift 5.9, SpriteKit, iOS 16+
  • Saves to UserDefaults as one JSON document
  • Probes for a server in the background — never blocks
  • Queues runs offline, uploads when one appears
  • 122 unit tests
The only link between them is HTTP and a handshake. The game requires protocol: "flappy-bird/1" before enabling anything online, so pointing it at the wrong port fails clearly instead of producing confusing errors later.

☁️ The backend

  • Node 20+, TypeScript, Express 5, Zod
  • PostgreSQL 16 — or an in-memory driver with zero setup
  • OpenAPI 3.1, Swagger UI bundled locally
  • JWT access tokens, rotating hashed refresh tokens
  • 106 tests, run against both storage drivers

Get started

Three commands, or one keystroke

You need Xcode. That is the whole dependency list for playing.

bash 
git clone https://github.com/hoangsonww/Flappy-Bird-Game.git
cd Flappy-Bird-Game
open "Flappy Bird.xcodeproj"   # then ⌘R
prefer the terminal? 
make doctor   # what you have, what it unlocks
make run      # build + launch in a simulator
make test     # 122 Swift unit tests
1

Clone and open

No package manager, no dependency resolution, no generated files to fetch. The project opens and builds.

2

Press ⌘R

Everything saves locally — scores, coins, skins, achievements, your ghost, and the daily challenge.

3

Optionally, make up

Postgres and the API start in Docker. Relaunch the game and it signs itself in as a guest.

4

Read the docs

Fourteen guides and three decision records covering architecture, the API, the schema, CI and the security model.
